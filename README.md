# Unnamed Animal Tracking Device

(Working title.)

A smart collar for the animal you love:

- **GPS tracking** — never lose them again.
- **POV camera** — see what they see, on your phone.
- **QR finder tag** — a printed tag so anyone who finds them can get them home fast.
- **Love signal** — one button that tells them you love them.

Security-first: multi-network Wi-Fi setup, encrypted everything.
